🚀 QUICK START

1. View Components in Action:
   $ npm run dev
   → Visit http://localhost:3000/components

2. Use Components in Your Code:
   import { Button, Input, Card, Badge, Spinner } from "@/components/ui";

   <Button variant="primary">Click me</Button>
   <Input label="Email" type="email" />
   <Card><CardHeader title="Title" /></Card>
   <Badge variant="success">Active</Badge>
   <Spinner size="md" />

3. Use Design Tokens:
   <div className="bg-primary-500 text-white p-base rounded-md shadow-md">
     Trustworthy design with semantic tokens
   </div>

4. Dark Mode (Automatic):
   All components work in light & dark modes
   Add ThemeToggle to navbar for user control
